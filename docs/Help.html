Getting started

There is nothing to install and nothing to sign in to. Put the exe wherever you like and double-click it, or drop a file onto the window, or right-click a file in Explorer and open it with Plain.

New asks which of the three to make - a spreadsheet, a document or a presentation - and then where to put it. It is written to disk straight away, so there is nothing to lose before your first save. On the command line it is plain new notes.docx, where the name decides the kind.

Several files can be open at once, each on its own tab along the top. Save writes the file back where it came from. Save a copy writes it somewhere new and leaves the original alone.

The promise, and what it means for your file

Most programs that open a .docx read it into their own idea of a document and write that back out. Anything their idea has no room for is quietly gone. Plain works the other way round: it opens the file as the package of parts it really is, and writes every part you did not edit back as the exact bytes it found.

Open a file, save it without changing anything, and you get the same file back, byte for byte. Change one cell and only the parts holding that cell are rewritten. The strip along the bottom of the window counts it every time you save.

The panel down the right names everything in the file that Plain is keeping but cannot draw: charts, pivot tables, macros, pictures, diagrams, tracked changes, comments, headers, footers, slide layouts, themes. Each one shows its size and what it is. None of them is touched.

Spreadsheets

Click a cell and type. What you type is read the way Excel reads it: a leading = makes a formula, something that looks like a number is a number, anything else is text. Enter moves down, Tab moves right, Delete empties a cell, F2 edits one without clearing it first. The bar above the grid shows and edits the selected cell.

Hold Shift with the arrow keys or with a click to select a block, then copy, cut or paste it. Cells travel as tab separated text, which is what Excel and every other spreadsheet put on the clipboard, so a block copied here pastes into Excel and the other way round. A cell holding a formula copies as its formula. A paste, however many cells it fills, is one step of undo.

Every sheet in the workbook is on the strip along the bottom. Column widths and number formats come from the file, so the sheet looks the way whoever made it laid it out.

About totals. Plain does not work out what a formula comes to. What it does instead is read which cells each formula depends on. When you change a cell, the formulas that read it lose the value Excel had worked out, and so do the formulas that read those, all the way up the chain and across sheets. Those cells show the formula until Excel or LibreOffice next opens the file and works them out properly. Every other total keeps its number. So changing one label does not empty the sheet, and no number on screen is one that has quietly stopped being true.

Documents

Click any line and type. Headings look like headings and tables look like tables, with their columns lined up.

Plain shows a document as one scrolling column with no page breaks, because laying pages out the way Word does needs Word's own fonts and line breaking, and guessing would be worse than not pretending. The strip along the bottom says so.

If you retype a paragraph that had several different formats inside it, say one bold word in the middle, that paragraph comes out in the first format throughout. Plain says so at the bottom of the window when it happens. Paragraphs you do not touch are not touched.

Decks

Pick a slide from the rail on the left and edit its text. Pictures, diagrams and shapes are not drawn and never move; they are held in the file exactly where they were.

When something goes wrong

Office can save the same document two ways, and the second way, which Excel calls "Strict Open XML", spells everything differently inside. Plain reads both and saves back whichever it found. A file it cannot make sense of is refused with an explanation rather than opened to an empty window.

A file that arrived damaged gets a sentence explaining what is wrong with it, never a crash. Plain's readers are tested against thousands of broken copies of real files: truncated downloads, zeroed blocks, flipped bits.

Saving writes the new contents beside your file first and only then puts them in its place, so a save that is interrupted leaves the original whole. Where the file already exists Plain replaces its contents rather than swapping in a new file with the same name, so the permissions on it, the date it was created and its place in the folder all survive.

If another program changed the file while you had it open, Plain notices and asks before writing over that. If Windows has the file marked read only, it says so and points you at Save a copy.

Honest limits

  • No page layout. If you need to see where the pages break, you need Word.
  • Formatting is bold, italic and heading level, and no more. No bullets, no fonts, no colours, no alignment. A heading can only be one the document already defines.
  • Printing and PDF give you the view, not Word's pagination. The PDF writes the Latin alphabet; other writing systems are not in the fonts a reader already has, and Plain says so rather than producing rubbish.
  • The interface is English only, and there is no right-to-left support in the editing surface.
  • Pictures can be looked at and saved out, but not placed or inserted.
  • Your own edits are not tracked changes. Plain can read, accept and turn down somebody else's mark-up, but it cannot make its own.
  • It does not draw shapes. Pictures, charts and diagrams are kept, listed and never rendered.
  • Mixed formatting inside one paragraph collapses if you retype that paragraph.
  • Password-protected files are refused rather than half-opened.
  • A package using ZIP64 records opens and re-saves unchanged, but will not be edited.
  • It is not a replacement for Office. It is what to reach for when you need to change three words in a contract without a four gigabyte install.
If the window comes up blank on a virtual machine or a remote desktop, start it with PLAIN_SOFTWARE_RENDER=1 set. Some virtual displays cannot present what Plain draws, and that setting draws it on the processor instead.

Command line

plain.exe is the same program as a console app, for scripts.

plain info <file>                what the file is, and what Plain keeps untouched
plain parts <file> [--json]      every part, and whether Plain shows it or preserves it
plain text <file> [--numbered]   the text, as plain text
plain cells <file> [sheet]       every filled cell, as reference<tab>value
plain get <file> <ref>           one cell, or one block by number
plain set <file> <ref> <value>   change one cell or block, then save in place
plain roundtrip <file>...        prove a save changes nothing: byte compares the result
plain selftest                   run the built-in checks

Exit codes: 0 fine, 1 something to look at, 2 problem, 64 usage.

Privacy

There is no network code in Plain at all. No account, no telemetry, no update check, nothing to turn off. It reads the file you open and writes the file you save, and keeps no settings, no recent-files list and no cache.
