Plain for Windows: opens Word, Excel and PowerPoint files, edits the basics, and never damages what it doesn't understand.

Every editor that opens a .docx reads it into its own idea of a document and writes that idea back out. Whatever it has no room for is quietly gone — the chart, the macro, the tracked changes, the header nobody looked at. You change three words and hand back something subtly different.

Plain opens the file as the package of parts it really is and writes back every part it didn't edit as the exact bytes it found.

Open a file, save it without changing anything, and you get the same file back byte for byte. That's a claim a test can check, and it's checked against real documents on every build — 39 of 39, including ones stuffed with macros and pivot tables.

It does the fifth of the job that fills most of the day: cells and formulas, sorting, filtering and de-duplicating rows, frozen headers, column widths, headings, tables and paragraphs, comments and tracked changes, the text on every slide, find and replace, page setup, print and PDF. When sorting would make a formula mean something else, it refuses and tells you which one, rather than guessing. It is in the Explorer right-click menu, and it checks GitHub once a day for a new version.

One exe. No installer, no account, no cloud, no telemetry. It asks GitHub once a day whether there's a newer version and that's the only thing it ever sends; turn it off and it makes no network request at all. Free and MIT.

There is a Mac one now as well, out today. Same program, Mac window, and the part that understands the file format is the same code compiled native, so the two agree about what a file is by construction rather than by intention.

Windows 10 or 11, Intel/AMD or ARM: https://github.com/keithadler/plainwin
macOS 14 or later, Apple Silicon and Intel: https://github.com/keithadler/plainmac
